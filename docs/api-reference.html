API reference

Every call, generated from the OpenAPI document the service serves (/openapi.json, also docs/openapi.json): 63 paths, 71 operations. All take Authorization: Bearer …; a person signed in with an OIDC token also sends KL-Workspace: <slug>. How to use them, with real examples, is in the guide.

Propose a thesis. If <change>, <outcome> will <reduce|increase|improve> by potentially <amount> <unit>. The amount is the product of the formula's numbers, researched at once: each is found in the graph (quoted from its document) or asked of a person. One change request. Answers: 202, 4xx problems.

ParameterInTypeAbout
